# Background and Text

The **Background** and **Text** cards in the inspector's **Design** tab set
the look of everything around the device.

## Background

Choose a **Type**:

| Type | Controls |
| --- | --- |
| **Solid** | One **Primary** colour |
| **Linear Gradient** | **Primary** and **Secondary** colours plus an **Angle** |
| **Radial Gradient** | **Primary** (centre) and **Secondary** (edge) colours |

Six presets give you a starting point: **Indigo Violet**, **Sunset**,
**Ocean**, **Forest**, **Graphite** and **Snow**. Pick one, then adjust the
colours if you like.

Backgrounds are set per media item. **Apply to all screenshots** (or **Apply
to all media**) copies the current background to every item in the frame.

> To use a picture as the background across a set of iPhone screenshots, use
> the **Panorama** card — see *Media*.

## Text

Each screenshot carries a **Title** and an optional **Subtitle**, always
centred above or below the device.

| Control | Effect |
| --- | --- |
| **Title** / **Subtitle** | The copy, in the language named in the card header |
| **Show subtitle** | Hides the subtitle line entirely |
| **Bold title** | Heavier title weight |
| **Above device** / **Below device** | Where the text block sits |
| **Text color** | Colour of both lines |
| **Title size** / **Subtitle size** | Point sizes, authored at full export size so they look the same on every canvas |
| **Horizontal offset** / **Vertical offset** | Nudges the block |
| **Rotation** | Tilts the text block |

**Apply to all screenshots** copies these settings to the other items in the
frame. In **Move** mode you can also drag the block on the canvas and click
it to edit the words in place.

The card header shows which language you are editing — the one selected in
the **Language** pop-up above the canvas. Text for other languages is edited
in the **Localization** tab or the **Localized Editor** window; see
*Localization*.

> Tip: keep titles short. Long headlines wrap on the narrow 6.1″ and 5.5″
> sizes even when they fit comfortably on a 6.9″ canvas — check the smaller
> frames before exporting.
