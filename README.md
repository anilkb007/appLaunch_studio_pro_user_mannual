# App Launch Studio Pro — User Guide

App Launch Studio Pro turns plain app screenshots and screen recordings into
finished App Store marketing images: a device frame, a background, a headline,
in every language you sell in — exported at the exact pixel sizes App Store
Connect accepts, or uploaded straight into your app's product page.

## Getting started

New here? Open **Getting Started** first — it walks through creating an app,
adding a frame, dropping in a screenshot and exporting it, and takes about
five minutes.

## Requirements

- macOS 26.5 or later.
- On-device auto-translation additionally needs **Apple Intelligence** turned
  on in System Settings. Everything else works without it.
- An App Store Connect API key is only needed for the upload features.

## Where your work is stored

Every change is saved automatically a moment after you make it. Your apps,
frames, media and templates live in the app's own Application Support folder,
so nothing is written next to your original screenshots.
